# FEYDA — النسخة المصححة لنموذج المنصة

FEYDA شبكة جزائرية توصل بين **الفريلانسر والتكوين والشركة/Startup والمورد** في مسار واحد: تشخيص المهارات → تكوين مناسب أو ملف كفاءة → فرصة مشروع → مورد للسلعة/المادة/المعدات. ملفات الواجهة وصفحات Cloudflare Functions وSQL موجودة هنا.

## تشغيل محليًا
```bash
npm install
cp .env.example .env.local
npm run dev
```
أدخل `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` في `.env.local`. نتيجة الإنتاج تحققت: `npm run build`.

## قاعدة البيانات
في Supabase SQL Editor نفّذ بالترتيب:
1. `supabase/schema.sql`
2. `supabase/network.sql`

تتضمن الجداول الأعضاء والأدوار، ملف المورد والمستقل، المنتجات، التكوينات، سجلات التقييم، فرص الشركات، دليل الموردين، واشتراكات المستقلين. الدورات الافتراضية في network.sql بيانات مثال فقط؛ استبدلها بعروض مدارس وفورماتورز موافقين عليها. حساب المورد أو الشركة لا يمنح دورًا لنفسه: مسؤول موثوق يهيئ `users`, `profiles`, وملف الدور. هذه الخطوة مطلوبة قبل تسجيل الدخول واستخدام المسارات المحمية.

## Cloudflare Pages وربط اسم فرعي
ارفع المشروع إلى GitHub، أنشئ Pages عبر Connect to Git، أمر البناء `npm run build`، ومجلد الناتج `dist`. أضف `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` كمتغيرات build. أضف الأسرار الخادمية `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `OPENAI_API_KEY`, واختياريًا `OPENAI_MODEL` من Pages → Settings → Variables and Secrets؛ لا تضع مفاتيح الخدمة أو OpenAI تحت متغير `VITE_`. في Custom domains اربط مثلًا `app.example.com` (لازم تملك النطاق ومضاف في Cloudflare)، ثم أضف عنوان النطاق إلى Supabase Auth redirect URLs.

## API
- `POST /api/ai/assessment` — تقييم مهارات إرشادي منظم بـ GPT-4o؛ أقل من 75 يقترح تكوينات، وعند 75+ يبحث عن فرص شركة مفتوحة مطابقة. التقييم ليس شهادة أو ضمان توظيف.
- `GET /api/opportunities` — فرص المشاريع المفتوحة، لحسابات المستقل/الشركة.
- `GET /api/formations` — عروض التكوين النشطة.
- `GET /api/suppliers` — دليل الموردين الموثقين، لحساب شركة.
- `/api/products` و`/api/products/:id` — إدارة كتالوج المورد. الأسعار DZD integer/bigint.
- `GET /api/talents?category=...` — ملفات الفريلانسر الموثقة.

## نموذج الأعمال المقترح داخل المنتج
- الشركة والـStartup والمورد: تجربة سنة أولى مجانية بموعد وشروط واضحة، وبعدها اشتراكات اختيارية/معلنة لأدوات متابعة الطلبات، المطابقة، وإدارة الموردين. لا تجديد مدفوع تلقائي مفاجئ.
- المستقل: مسار أساسي مجاني، مع اشتراك اختياري لخدمات قيمة مثل بورتفوليو متقدم، تنبيهات، وتحليلات؛ لا تحجب فرص أساسية عن غير المشترك.
- مدرسة/فورماتور: إدراج برامج موثقة ثم إحالة/عمولة باتفاق واضح. لا تعرض السعر أو الخصم كحقيقة إلا بعد اعتماد الشريك.

## جاهزية الإنتاج
أضف قبل الإطلاق: إدارة أدوار/ملفات داخلية، rate limits على AI، مراجعة بشرية/تحديات عملية للتحقق المهني، حماية إساءة الاستخدام، اختبارات للمسارات، مراقبة ونسخ احتياطي، موافقات الخصوصية، ومراجعة شروط تجارية وقانونية. صفحة الواجهة هي نقطة انطلاق متكاملة وظيفيًا بصريًا؛ الوظائف الحية تتطلب مفاتيح Supabase/OpenAI وبيانات شركاء حقيقية.
